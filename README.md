# تاپ‌شارژ — نسخه آماده اتصال به درگاه واقعی

این پروژه یک فروشگاه شارژ با رابط فارسی/RTL، انتخاب اپراتور، مبلغ، شماره موبایل و ساخت سفارش دارد.

## اجرا

1. Node.js نصب باشد.
2. داخل پوشه پروژه:
   npm install
   npm start
3. مرورگر را روی http://localhost:3000 باز کنید.

## فعال‌سازی پرداخت واقعی

- یک درگاه پرداخت مجاز تهیه کنید.
- Merchant ID/کلیدهای محرمانه را فقط روی سرور و در متغیرهای محیطی قرار دهید.
- تابع `createGatewayPayment` در `server.js` را طبق مستندات رسمی همان درگاه پیاده‌سازی کنید.
- callback را با API رسمی درگاه verify کنید و فقط بعد از تأیید قطعی تراکنش، سفارش را «پرداخت‌شده» کنید.
- برای تحویل شارژ نیز از API رسمی تأمین‌کننده شارژ استفاده کنید؛ اطلاعات محرمانه را هرگز داخل `public/` نگذارید.
- حساب تسویه باید متعلق به صاحب مجاز درگاه باشد.

این پروژه عمداً اطلاعات درگاه، کلیدها و احراز هویت را جعل یا دور نمی‌زند.
